# FinCheck — AI金融建议越界判定核

**v0.1.0** | MIT | 零依赖纯Python | 中英双语规则 | 与 [QMed](https://github.com/PHM-Audit/qmed)（医疗）同构

确定性规则引擎，判定 **AI生成的金融建议是否越过公开监管边界**。不预测涨跌，只判结构。

> 判定对象是 AI 输出的建议结构，不是市场方向。
> 核心问题："这条建议是否越过确定性边界？"——而不是"这只股票会不会涨？"

## 为什么现在

- 中国证监会于 2026 金融街论坛宣布发布实施 **《人工智能在证券期货业安全合规应用的意见》**，直指算法黑箱、模型幻觉、人工监督底线（来源：证监会官网吴清主席主题演讲，见 SOURCES.md）。
- 八部门 **《金融产品网络营销管理办法》** 已于 2026-09-30 施行：AI 输出的个股推荐、买卖点位、持仓建议属倾向性指导内容，按业务定性须持牌；"AI 自动生成、无人工干预"不能作为免责抗辩（来源：公开报道解读，见 SOURCES.md）。
- 美国侧：SEC 对 robo-advisor 适用与人类顾问相同的信义义务——2026-03-23 对 Ally Invest Advisors 的行政令（ia-6954，违反 Advisers Act §206(2)，Cash-Enhanced robo 产品）；SEC 2026 财年考试优先级将 AI/新兴技术列为重点领域（来源：sec.gov，见 SOURCES.md）。

监管落地窗口内，机构需要一个 **可审计、可复算、规则判定无随机性** 的输出校验层。FinCheck 提供的是确定性规则核——同一输入永远同一输出，SHA-256 可锁定审计链。

## 规则族（三态出口 PASS / FLAG / VETO）

| 规则 | 判定内容 | 出口 | 监管锚 |
|---|---|---|---|
| **F1** 资金边界越界 | 全仓/借贷杠杆/生活费投入类建议（负语境劝阻自动免判） | VETO | 投资者适当性原则 |
| **F2** 事实自洽缺口 | 绝对化收益承诺（稳赚/guaranteed）无风险披露；"内部数据/神秘指标"类不可复算来源；固定高收益率承诺 | FLAG | AI应用意见-算法幻觉条款；《办法》收益宣传披露要求；SEC固定收益承诺口径 |
| **F3** 资质规避话术 | 具体荐股指令（代码/目标价/仓位指令+买卖动作）+"不构成投资建议"式免责的组合 | VETO | 《办法》第七条主体责任+业务定性条款 |
| **F4** 否定专业监督 | 劝阻财报核查/持牌咨询（"财报没用""投顾都是割韭菜"） | VETO | 与AI应用意见人工监督底线同构 |
| **F5** 无资质荐股结构 | 付费会员引流+荐股；黑马股话术+操作指令 | FLAG | 《办法》业务定性 |

出口规则：任一 VETO → **VETO**；仅 FLAG → **FLAG**；无违例 → **PASS**。

## 快速开始

```python
from fincheck import check_text

res = check_text("利智投AI智能投顾: 目标价50元，600000买入，年化收益高达35%，稳赚不赔，本内容不构成投资建议。")
print(res["verdict"])   # VETO
for v in res["violations"]:
    print(v["rule"], v["severity"])
```

命令行:

```bash
python3 fincheck.py your_text.txt
python3 test_fincheck.py   # 22用例回归
```

## 已知边界（诚实披露）

1. **负语境判定使用窄警示词表**（请勿/禁止/never use…前80字符窗）。理论上"严禁犹豫，马上借钱炒股"类组合可能绕过——v0.1 已知局限，v0.2 计划句法级处理。
2. **F2 的"建议-公开数据一致性"在 v0.1 是结构检查**（来源可验证性/收益承诺结构），真正的财报数字比对需要外接行情/财报数据源——接口已预留（`F2_MAGIC_SOURCE` 命中即提示应外接复算）。
3. **文本层最高 FLAG 到 VETO**：无资质荐股的最终 VETO 定性需运行时资质核查数据（输出主体牌照），判定核输出的是结构证据而非资质结论。
4. 重构输入不是案例原始文本：T1 案内回放基于来源确认的事实要素重构，逐字原文未公开。

## 定性边界（重要）

- **本工具输出不构成法律意见、合规意见或投资建议**——它是结构证据收集器。
- **VETO = 规则命中，不等于对输出主体的违法定性**——最终定性由监管机构/司法机关判断。
- **规则词表与阈值公开可复算，但不保证覆盖全部越界形态**——v0.x 覆盖公开案例确认的结构特征。

## 与 QMed / MedCheck 的关系

同一判定核配方（五规则族 + 三态出口 + 语言无关词表 + 零依赖）在垂直领域的第三个实例：

- **QMed/MedCheck**：医疗建议边界（万博雯案五规则族，33/33）
- **FinCheck**：金融建议边界（本仓，监管条文映射，22/22）
- **RobotCheck**（规划）：机器人物理动作边界

设计立场：**确定性规则做守门，不确定性判断留给持牌专业人士**——AI 输出先过结构校验，越界即拦截，疑似越界即升级人工复核。
